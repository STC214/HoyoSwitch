# 原神账号状态点位与切换文件（2026-11-19 实测）

- 设备：Xiaomi 23117RK66C（fuxi），Android 16 / SDK 36，Root（KernelSU）。
- 游戏：原神 `com.miHoYo.Yuanshen` 7.2.0（versionCode 1257），入口 `com.miHoYo.Yuanshen/com.miHoYo.GetMobileInfo.MainActivity`。
- 方法：分别对「完全登出」与「登录账号 A（159 / mid `0a0ycvi51n_mhy`）」两种状态，对
  `/data/user/0/com.miHoYo.Yuanshen/{shared_prefs,databases,files}` 全量文件做 SHA-256 指纹并 diff。

## 1. 与星铁的差异

| 项目 | 星铁 | 原神 |
| --- | --- | --- |
| 账号窗口缓存 | `shared_prefs/combo_widget.xml`（`account` 字段含 `mid`） | 无 combo_widget |
| token | `shared_prefs/porte_sdk_token_PRODUCT.xml` | 同文件，但**登录后才会出现** |
| 账号标识 | combo_widget 的 `account.mid` | token prefs 的 key 前缀：`<mid>_mhy_porte_cookie_token_key` |
| 账号库 | `databases/PORTE_ACCOUNT_PRODUCT.db` | 同库，`porte_account_table`（`mid, aid, type, timestamp, data`），登出时为空表 |
| login_status | `porte_sdk_account_PRODUCT.xml` 的 `login_status` | `porte_sdk_account_PRODUCT.xml` 也存在，但登出时仍为 `true`，**不可作为登录判据** |

实测登录后 `porte_account_table` 一行：

```
mid=0a0ycvi51n_mhy  aid=346975607  type=2  data=<加密 blob>
```

`data` 与 `porte_sdk_token_PRODUCT.xml` 的 `<string name="0a0ycvi51n_mhy_mhy_porte_cookie_token_key">` 内容一致。

## 2. 登出 → 登录 的文件变化

- 新增：`shared_prefs/porte_sdk_token_PRODUCT.xml`、`shared_prefs/astrolabe.xml`、
  `shared_prefs/com.miHoYo.Yuanshen_preferences.xml`、`databases/mihoyo-shenhe`、
  `files/persistentDataPath` 等运行时文件。
- 变化：`databases/PORTE_ACCOUNT_PRODUCT.db`（写入账号行）、`shared_prefs/mihoyo_sdk_preference.xml`
  （SDK 配置/会话）、`shared_prefs/com.miHoYo.Yuanshen.v2.playerprefs.xml`（画质等）。
- 含 `mid` 的文件仅两个：`porte_sdk_token_PRODUCT.xml` 与 `PORTE_ACCOUNT_PRODUCT.db`。
