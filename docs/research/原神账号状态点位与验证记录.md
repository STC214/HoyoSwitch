### 3.1 当前账号判定：不能取 token 的第一个 key

登录过两个账号后，`porte_sdk_token_PRODUCT.xml` 里会**同时存在两个 key**：

```
<string name="0a0ycvi51n_mhy_mhy_porte_cookie_token_key">…</string>   <!-- A -->
<string name="0032ruoysk_mhy_mhy_porte_cookie_token_key">…</string>   <!-- B -->
```

所以「第一个 key」不代表当前账号。可行判据是账号库：`porte_account_table` 每行形如
`<mid><aid><type><13 位时间戳><加密 blob>`，**timestamp 最大的那一行就是当前账号**。
App 里用正则 `([0-9a-z_]+_mhy)(\d+)(\d{13})` 扫描 DB 字节，取最大时间戳对应的 mid；
拿不到时再退回 token key 首项。
